# Clipboard Image Resizer

Отдельный инструмент для быстрого просмотра обычной картинки в размерах,
используемых генератором: 16×16, 32×32, 64×64 и т.д.

## Что умеет

- взять изображение прямо из системного буфера обмена;
- задать точную ширину и высоту;
- три режима:
  - Stretch — растянуть ровно в W×H;
  - Fit — сохранить пропорции и добавить чёрные поля;
  - Cover — сохранить пропорции и обрезать лишнее по центру;
- фильтр Nearest или Smooth;
- показать исходник и результат рядом;
- скопировать результат обратно в буфер;
- сохранить PNG.

## Запуск

Из корня репозитория:

```powershell
python tools\clipboard_resizer\main.py
```

Используется тот же PySide6, поэтому дополнительных зависимостей не требуется.

Для экспериментов с пиксельной структурой обычно полезно начать с:

- 64×64;
- режим Cover;
- фильтр Nearest.

Так можно посмотреть, как известное осмысленное изображение выглядит в том же
размере, в котором генератор перебирает случайные RGB-кадры.


## Sanity check

После уменьшения нажмите `Sanity check: MVP + Robust`.

Инструмент принудительно считает оба анализатора для трёх образцов одного размера:

1. исходное уменьшенное изображение;
2. те же RGB-пиксели, случайно перемешанные по позициям;
3. чистое IID RGB-random изображение.

В результате выводятся MVP/Robust score и PASS/fail для всех трёх, а для
исходного изображения — ключевые MVP-метрики и Robust z-score.

Это быстрый одиночный контроль. Он проверяет, что процедурные анализаторы реагируют
на пространственную структуру, но не заменяет будущий batch-тест на сотнях или
тысячах реальных изображений.
