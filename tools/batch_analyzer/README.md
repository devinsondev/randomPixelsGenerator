# Image Batch Sanity Analyzer

Пакетный sanity-check для папки с обычными изображениями.

## Запуск

Из корня репозитория:

```powershell
python tools\batch_analyzer\main.py
```

## Что делает

1. Выбирает папку и при необходимости рекурсивно сканирует подпапки.
2. Загружает PNG/JPEG/BMP/WebP/GIF/TIFF.
3. Приводит каждую картинку к заданному размеру, по умолчанию 64×64.
4. Принудительно считает MVP и Robust для:
   - реального изображения;
   - тех же пикселей, перемешанных по позициям;
   - IID RGB-random контроля того же размера.
5. Показывает одну строку на файл.

Таблица содержит маленький 8×8 или 16×16 preview исходного изображения,
исходный размер и шесть score-колонок Real/Shuffled/Random × MVP/Robust.

Анализ идёт в отдельном QThread, поэтому UI остаётся отзывчивым. Кнопка отмены
останавливает batch после завершения текущего файла.

По завершении сверху показываются средние score по всей папке.
